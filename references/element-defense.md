# 单项请求权与攻防检视

目录：一、要件卡；二、要件检视行；三、请求方阶段；四、相对方阶段；五、抗辩分类；六、多项请求权覆盖；七、反诉与抵销；八、法律效果；九、结论句。

## 1. 要件卡

每个候选请求权建立一张卡：

- `claim_id / basis_id`
- 请求人、相对人、法律效果
- 直接请求权基础：规范全称＋条/款/项，或法律行为名称＋条款号＋`source_id`定位
- 法定法律效果、请求权基础完整性与“该条款能否直接推出本项请求”检查
- 其他规则：分别用中文列明辅助/构成规则、行为归属规则、金额/范围/计价规则、证明规则、抗辩/限制规则和程序规则及其作用
- 官方法源、核验日期、时间效力和当前有效性
- 积极要件
- 权利未发生事由
- 权利消灭/变更事由
- 权利行使抗辩或限制
- 法律效果范围、计算、履行方式
- 候选基础之间关系

卡片没有具体直接请求权基础时不得开始三层四步。只有“待核法源”的候选应停留在检索阶段并将结论标为 `待核法源`。

## 2. 要件检视行

每一要件至少记录：

| 字段 | 内容 |
|---|---|
| 问题 | 该要件需要回答的最小问题 |
| 标准 | 法律定义、判断因素、争议观点与来源 |
| 请求方陈述 | 仅记录请求方版本及不利自认 |
| 相对方回应 | 承认、否认、抗辩或法律意见 |
| 证据 | 现有证据及证明对象 |
| 证明责任 | 原则分配及特别规则 |
| 涵摄 | 为什么满足/不满足，缺什么 |
| 结论 | 已满足、附条件满足、目前不满足、无争议、待证、待核法源 |

不要把整份合同或整段故事塞入一行。复合要件必须拆分。

## 3. 请求方阶段

问题：仅按请求方自己的事实陈述，其诉请是否在法律上足够？

- 遍检所有候选基础，不因一项足够就停止。
- 审查请求方对己不利的陈述，例如已履行、已免除、无权代理、标的灭失。
- 对请求权产生要件和请求方自己陈述的未发生/消灭事由一并检视。
- 未满足时指出缺少的是事实主张、法律依据还是证据；此阶段主要判断陈述，不提前混入真实性判断。

## 4. 相对方阶段

### 否认

相对方否定请求方应负证明责任的要件事实。原则上并不因否认而承担该积极事实的证明责任，但可能需要具体化说明或承担反证风险。

### 独立抗辩

相对方提出新的、足以阻却/消灭/限制请求权的事实。通常由提出者承担相应主张与证明责任，特别规则除外。

### 法律意见

单纯说“我不应承担责任”不是事实抗辩。必须找出其背后有无可对应防御规范的具体事实。

## 5. 抗辩分类

### 权利未发生

例如法律行为不成立、无效、效力未定未获追认、主体/处分权欠缺且无替代规则、请求权特别要件缺失等。具体内容必须按现行法核验。

### 权利已消灭或变更

例如履行、解除后原请求消灭、抵销、提存、免除、混同、更新/和解、债权转让后主体变化等。

### 权利行使受阻或限制

例如诉讼时效抗辩、同时履行/先履行/不安抗辩、期限未届、顺位利益、留置、责任限制或先诉抗辩等。

### 抗辩的例外

对每项抗辩继续问：是否存在无效、失权、放弃、承诺履行、再抗辩、权利滥用限制或其他排除事由。

## 6. 多项请求权覆盖测试

建立防御覆盖表：

| 防御 | 基础 A | 基础 B | 基础 C | 是否完整覆盖 |
|---|---|---|---|---|

如果诉请有三项可行基础，被告抗辩只击穿其中两项，不得据此直接得出原告败诉。

## 7. 反诉与抵销

- 抗辩用于阻止或减少原告诉请；反诉追求独立裁判结果。
- 抵销可能是实体抗辩、诉讼抗辩或与反诉策略交织，必须按现行程序规则和具体主张形式核验。
- 对方主张超过“驳回原告诉请”的法律效果时，评估是否必须反诉或另诉。

## 8. 法律效果检视

请求权成立不等于请求金额全部成立。另审：

- 责任方式是否可并用或择一。
- 本金、范围、因果关系、可预见性、减损、与有过失、损益相抵、责任限额。
- 履行可能性、替代履行、价额返还、利息起算、违约金调整。
- 连带、按份、补充、顺位、追偿等责任形态。
- 判项是否具体、可执行。

## 9. 结论句

使用条件化表达：

> 在【待核事实】能够由【证据】证明、且【法源/抗辩】经核验不改变结论的前提下，请求人基于【规范】提出【法律效果】的路径目前属于【状态】；最可能的阻断点是【要件/抗辩】。
